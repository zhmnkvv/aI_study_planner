# aI_study_planner

## Что мешает при использовании

Наблюдения по результатам ручного тестирования инструмента:

1. **Нельзя отредактировать добавленную задачу.** Если допущена ошибка в названии, продолжительности или приоритете, задачу приходится удалять и добавлять заново.

2. **Перерывы нельзя настроить или отключить.** Перерывы добавляются автоматически (сейчас — 15 минут после длительной задачи), но пользователь не может изменить их продолжительность или отказаться от них.

3. **Нет подсказки, как использовать оставшееся время.** Если часть свободного времени остаётся незаполненной, инструмент просто показывает, сколько его осталось. Было бы полезно подсказать пользователю, что с ним сделать — например, предложить добавить ещё одну задачу или оставить это время свободным.

4. **Длинное расписание неудобно просматривать.** При большом количестве задач расписание становится длинным; в дальнейшем можно улучшить визуальное отображение, чтобы план было удобнее быстро просматривать.
